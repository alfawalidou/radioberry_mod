# Contributing

Contributions that improve build reproducibility, SDR integration, hardware notes, or documentation are welcome.

## Guidelines

- Document the Raspberry Pi, FPGA/radio hardware, and software versions involved.
- Keep configuration changes focused and explain any assumptions about sample rates or interfaces.
- Do not commit credentials, private keys, tokens, or machine-specific secrets.
- Include reproduction steps for build, driver, audio, or network issues.
- Keep radio use within applicable local regulations and authorized frequencies.

Pull requests should explain what changed, why, and how it was validated.
